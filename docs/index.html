Custom BeautifulSoup4 parsing engine with pagination traversal, exponential retry jitter (max 3 retries), SHA-256 fingerprint deduplication, and automated offline fixture failover for 100% reproducible testing.

Task 2: Automated Data Cleaning & Schema Normalization
Entry point: projects/task_2_quality/run.py

Harmonizes heterogenous schemas into standardized snake_case, parses varied timestamp strings to ISO-8601 (YYYY-MM-DD), decomposes complex salary ranges into numeric integers, and isolates invalid inputs into a dead-letter ledger.

$ python projects/task_2_quality/run.py
